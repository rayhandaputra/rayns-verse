# Customer Dashboard Widgets

### Widget: HeroCampaign
- File: `HeroCampaign.tsx`
- Function: Hero campaign dengan CTA tunggal "Buat ID Card kamu sekarang" — personalisasi nama, trust badges, dan tombol aksi kontras tinggi
- Props: `fullname?: string`

### Widget: ProductList
- File: `ProductList.tsx`
- Function: Carousel horizontal produk dari API (show_in_dashboard) dengan harga mulai dan tombol pesan
- Props: `products: any[]`

### Widget: LatestProduction
- File: `LatestProduction.tsx`
- Function: Daftar produksi terbaru (order selesai + portfolio) dengan foto, instansi, jumlah pcs, dan review
- Props: `items: any[]`
